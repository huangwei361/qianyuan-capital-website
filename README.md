# 乾元资本集团官网

> 1 集团 + 7 家子公司（筹备中）· 5-8 年长期主义规划

乾元资本集团筹备期个人网站，记录集团母体的 5-8 年战略规划。包含集团架构、7 家筹备子公司的子网页、乾元出海的外贸公司网站等。

## 项目结构

```
website/
├── index.html              # 集团主站
├── qifu.html               # 乾元企服
├── gold.html               # 乾元黄金
├── global.html             # 乾元出海（介绍）
├── global-shop.html        # 乾元出海·全球精选（外贸商城）
├── quant.html              # 乾元量化总览
├── quant-trading.html      # 交易事业部
├── quant-rd.html           # 研发事业部
├── invest.html             # 乾元投资
├── rental.html             # 乾元租赁
├── asset.html              # 乾元资产处理
│
├── style.css               # 主站样式
├── _sub.css                # 子站共享样式
├── quant-trading.css       # 量化交易子站独立样式
├── quant-rd.css            # 量化研发子站独立样式
├── main.js                 # 主站交互
│
├── _gen.py                 # 7 个标准子站批量生成脚本
├── README.md               # 本文件
│
└── assets/
    └── img/                # 9 个 Logo + icon
```

## 部署

所有 HTML 平铺在网站根目录。任意外部 web server 即可托管：

```bash
# 本地预览
python -m http.server 8000

# 部署到 hoshin.xin（个人 ICP 备案）
# 把整个 website/ 目录上传到服务器
```
