关于 乾元投融资规划和管理

乾元投融资规划和管理是集团旗下的集团级业务集群（原乾元投资升级），
下设 3 大业务：投融资主业（找钱 + 用钱 + 循环）+ 乾元企服（内部资金中心）+ 乾元资产处理（不良资产价值重塑），
通过业务协同实现长期复利增长。

核 心 内 容

乾元投融资规划和管理 业务模块

📈 投 融 资 主 业

核心业务：融资（找钱）+ 投资（用钱）+ 两者结合的循环。
把外部资金引到乾元系（股权/债权/信用/众筹），再把资金配置到能产生收益的资产（战略/财务/不动产/海外），通过业绩→信用→再融资的飞轮放大。

💼 乾 元 企 服

集团内部资金中心，8 大职能模块：
资金归集 / 投资调度 / 融资支持 / 税务福利 / 风控合规 / 战略投资 / 福利社保 / 内部审计。

⚖️ 乾 元 资 产 处 理

不良资产价值重塑：
法拍房（司法拍卖捡漏）/ 不良债权（AMC 收购 / 催收 / 重整）/ 困境企业（经营困难企业重组）。
5 年内只学习不实操，专业门槛极高。

融 资 方 法 论

3 要素 · 3 阶段 · 3 策略 · 7 步法

融资不是"求人借钱"，而是用信用 + 身份 + 筹码 撬动外部资金的系统工程。
融资本质是经营 + 杠杆 + 复利的三位一体，融资规模超过 3000 万，一定是有资产在名下。

① 融资 3 要素

① 信用
信 用
CREDIT · 征信 + 流水
  • 征信报告（无逾期）
  • 社保 / 公积金连续缴纳
  • 信贷记录（信用卡 / 信用贷使用情况）
  • 经营流水（个人 / 公司）
信用是融资的门票，没有信用连第一道门都进不去
② 身份
身 份
IDENTITY · 学历 + 户口 + 单位
  • 学历（大专以上加分）
  • 户籍 / 户口（北上广深加分）
  • 房产 / 车产（名下资产）
  • 稳定工作 / 经营年限（> 2 年）
身份是融资的加分器，好身份可以拿到更低利率
③ 筹码
筹 码
CHIPS · 营收 + 资产 + 抵押
  • 营收流水（年流水 100 万+）
  • 名下资产（房 / 车 / 股权）
  • 抵押物（评估价 vs 成交价）
  • 经营年限（> 2 年有加成）
筹码是融资的杠杆，筹码越多融资规模越大

② 4 大融资类型

🏦 银行类
银 行
  • 营收贷（100 万流水可贷 100 万）
  • 信用贷（身份证 + 公积金）
  • 抵押贷（评估价 7-8 成）
  • 按揭（首套 30%）
🏛️ 政策类
政 策
  • 创业基金（最高 50 万 / 3 月）
  • 科创委（最高 300 万 / 9 月）
  • 土地抵押
  • 接力贷（30 年低息）
⚡ 特殊类
特 殊
  • 当铺 / 物业贷（1 万月息）
  • 连锁贷（品牌背书）
  • 股权质押
  • 保单 / 理财质押
🤝 民间类
民 间
  • 小额信贷（3 万内）
  • 亲友拆借
  • 联合众筹 / 项目跟投
  • 股权出让融资

③ 3 大融资策略

🛡️ 背书型
背 书 型
ENDORSEMENT
  • 用别人的资产给自己背书
  • 老板名下没房，但朋友名下有豪宅
  • 借他人信用 + 资产作担保
  • 适合：早期无资产的创业者
风险：背书人违约 = 自己承担连带责任
💰 套现型
套 现 型
CASH-OUT
  • 银行评估价 2000 万的房子
  • 抵押 7-8 成 = 套出 1400-1600 万
  • 下行期买不良资产（评估价 1000 万，300 万拿下）
  • 套出现金用于再投资
这是不良资产价值重塑的底层逻辑
📈 杠杆型
杠 杆 型
LEVERAGE
  • 上浮 12% + 30 年接力贷
  • 最小首付买最大的房
  • 用杠杆放大资本回报率
  • 适合：长期看涨的资产
杠杆是双刃剑，必须先评估下行风险

投融资循环 · 自我增强

乾元投资不是"先融资再投资"的两段式，而是投融资一体化的飞轮：
融到的钱 → 投出去产生业绩 → 业绩建立信用 → 信用反哺下一轮融资，
每一轮循环都让飞轮转得更快、融得更多、投得更准。

融 · 投 · 绩 · 信 · 再融
